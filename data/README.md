# data/

Raw Olist CSVs go here. **They are git-ignored** (large, and provided via Canvas — not ours to redistribute).

## How to get the data
Download the Olist dataset from **Canvas ▸ Week 1** and place the 9 CSVs in this folder:

```
data/
├── olist_customers_dataset.csv
├── olist_geolocation_dataset.csv
├── olist_orders_dataset.csv
├── olist_order_items_dataset.csv
├── olist_order_payments_dataset.csv
├── olist_order_reviews_dataset.csv
├── olist_products_dataset.csv
├── olist_sellers_dataset.csv
└── product_category_name_translation.csv
```

For Colab, instead put them in Google Drive at `MyDrive/IT5006_Project-Data/Olist_CSV/`.
The notebooks read from Drive in Colab and fall back to this `data/` folder locally.
