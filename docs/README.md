# docs/

Project documentation: the Phase 1, Phase 2 and final reports and the presentation slides.

These are graded deliverables, so they are submitted on Canvas and kept out of this public repository; this
folder holds them locally only. Everything needed to reproduce the results is versioned elsewhere:

- `notebooks/` — the Phase 1 EDA and the Phase 2 modelling notebooks
- `src/` — the feature, model and evaluation code the notebooks call
- `deployment/` — the Phase 1 EDA dashboard and the Phase 3 model app

See the `README.md` at the repository root for setup and run instructions.
